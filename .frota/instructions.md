- Mocks de UI: crie o HTML em `docs/mocks/` e abra pelo caminho com `open docs/mocks/<nome>.html` (navegador do sistema), ou mostre o caminho para a pessoa. Não suba servidor HTTP só para isso. O navegador integrado da Frota não abre `file://`, então mock não passa por ele.
- Navegador integrado da Frota: use-o para páginas http/https (app rodando, dev server, site) SOMENTE quando ele chegar até você pelo MCP de navegador do projeto, o que hoje acontece só no Claude Code e no Codex. Se essa ferramenta não está na sua sessão (agy e outros motores), não abra navegador nenhum por conta própria: nada de tool nativa de navegador, MCP de Playwright ou parecido, `npx playwright`, `open -a`. Diga o que queria verificar e peça o gesto à pessoa.
