Decisões

  • P1. Reconhecimento por palavra, sem modelo. Recomendo: previsível, instantâneo, e cada pergunta tem teste. O custo é não entender perguntas fora da tabela, e aí a paleta faz o de hoje.
  • P2. A linha de estado com o campo vazio. Recomendo manter; some quando não há nada rodando nem pedindo.
  • P3. "Perguntar ao modelo auxiliar" como item para pergunta não reconhecida: recomendo deixar para depois.
  • P4. Escopo: as respostas cobrem todos os projetos (a Frota é uma só). "neste projeto" na pergunta filtra para o projeto aberto.
