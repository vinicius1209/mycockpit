Sistema de avatar — escolha a direção

Cada bloco é um sistema COERENTE: um estilo base só + a cor vinda da categoria (paleta LABEL_COLORS do app) + seed = nome. Compare os times lado a lado e diga qual leva a identidade a sério. Depois eu conecto no avatar.ts.

Renderizado via API do DiceBear só pra escolher a direção (precisa de internet). No app é @dicebear/core offline, determinístico. Nenhum destes usa o estilo cru "por especialista" — a cor é derivada da categoria, então o time é sempre uma família.
