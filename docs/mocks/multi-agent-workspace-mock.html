A complexidade é moderada, mas a chave é separar o leitor de diffs da casca da janela. Hoje o DiffPanel é apenas um container de leitura rápida, mas podemos torná-lo um visualizador com seleção de trecho e atalhos de citação.

Para habilitar a seleção de trechos com highlight e envio direto para o composer (estilo "Citar no chat"), precisamos de três coisas estruturais:

1. Captura de Range de Linhas: Mapear o evento onMouseUp nas linhas do diff para emitir o payload com o caminho do arquivo e intervalo (ex: [MainTabs.tsx#L42-L65]).
2. Injeção no Composer: Conectar ao useComposerDrafts.setText com a referência anexada pronta para o próximo envio.
3. Largura Dedicada: Como observamos no Orca e no Paseo, um diff só respira se tiver piso mínimo de 420px.
