Árvore de arquivos: o .env e a busca agrupada

Dois assuntos, com os seus dados. (1) O .env não é filtrado por nome: a árvore segue o .gitignore de cada projeto, e é a mesma regra que esconde node_modules e dist. (2) A busca de hoje mostra só o nome do arquivo, numa lista corrida. Com o projeto projetos (40 pastas), "config" traz dez tsconfig.json iguais, e não dá para saber de qual projeto é cada um. Os resultados abaixo são da sua pasta, colhidos agora.

O .env quase sempre tem chave de API. A prévia abre com os nomes à vista e os valores escondidos, e um clique mostra. Assim, abrir para conferir se a variável existe não põe a chave na tela (print, compartilhamento). É só visual: o arquivo não muda, e o agente lê do disco como sempre.

O que vale para os dois para você conferir

Num projeto comum (uma pasta só, como o frota), o agrupamento usa a pasta de primeiro nível (app, docs, scripts), e com um grupo só ele não aparece: fica a lista, com o caminho relativo à direita. O agrupamento é só na tela: a busca continua paginada no Rust, e o "Carregar mais" traz a próxima página para dentro dos grupos.
