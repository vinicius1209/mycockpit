M1: Delivery Recall (Memória Episódica)

Quando você digita uma nova tarefa, o sistema tokeniza os requisitos e compara com entregas passadas aprovadas nos gates.

Score = (Overlap_Keywords + Overlap_Paths) / 2 • Score ≥ 0.50 → Injeta plano anterior no prompt • Score < 0.15 → Descarte silencioso (zero ruído)
M2: RLHF Local & Ranking de Relevância

O prompt nunca cresce infinitamente. Ele seleciona estritamente as regras de maior pontuação acumulada por feedback real.

SELECT * FROM lessons WHERE status = 'active' AND (scope = 'global' OR project_id = $1) ORDER BY uses DESC, created_at DESC LIMIT 8;
🛡️ Estratégia de Resiliência: E se o Haiku estiver offline?

No MyCockpit, a destilação de regras é projetada para ser tolerante a falhas (fail-safe graceful degradation). Nenhuma falha de rede ou de API pode interromper o fluxo de trabalho do desenvolvedor.

Fallback 1: No Código Hoje
Pass-Through Cru (Zero Bloqueio)

Se helperModel for null ou a API falhar, o sistema devolve imediatamente a própria nota digitada pelo desenvolvedor no card editável.

if (!helperModel) { return { rule: note, learnable: null } }
Fallback 2: macOS On-Device
Apple Foundation / CoreML

No macOS 15.1+, o sistema operacional possui modelos locais rodando no Apple Neural Engine. Eles são perfeitos para destilar frases em 30ms com zero custo de API e 100% de privacidade.

// Sidecar Swift / CoreML let distilled = try await AppleIntelligence.summarize(feedback)
Fallback 3: Local LLMs
Ollama / MLX / Qwen 1.5B

Modelos pequenos especializados em código (ex: qwen2.5-coder:1.5b ou llama3.2:1b) consom menos de 1GB de RAM e executam localmente no backend Rust.

// Chamada local via IPC Rust let rule = run_local_mlx(prompt).await;

📚 Fundamentação Teórica e Literatura Científica

A arquitetura do MyCockpit não é empírica ao acaso: ela implementa os princípios formais descritos nos papers mais influentes da literatura de agentes autônomos e aprendizado em tempo de execução:

📚 Estado da Arte: Pesquisas & Papers Recentes (2024–2026)

A literatura de agentes de IA evoluiu drasticamente entre 2024 e 2026, consolidando o paradigma de Experience-driven Lifelong Learning (Aprendizado Contínuo sem Fine-Tuning). Veja os principais artigos recentes que fundamentam o MyCockpit:

arXiv:2026 / SWE-bench Verified · SOTA
MemCoder: Your Code Agent Can Grow Alongside You with Structured Memory
Z. Liu, H. Zhang, Y. Wang, et al. (2026)
Como o MyCockpit aplica: Propõe a "auto-internalização de experiência" para agentes de software: transforma correções humanas e testes em regras estruturadas de longo prazo que co-evoluem com o repositório, atingindo SOTA no SWE-bench.
arXiv:2025 / AAAI · Self-Evolution
AgentEvolver: Towards Efficient and Autonomous Self-Evolving AI Agents
J. Chen, R. Sun, X. Li, et al. (2025)
Como o MyCockpit aplica: Modela a Self-Attribution (atribuição de crédito e recompensa a regras anteriores). É exatamente a lógica por trás do nosso botão 👍 (reinforceLessons), recompensando regras que levaram ao sucesso da entrega.
ICLR / arXiv 2026 · Memory Taxonomy
Memory for Autonomous LLM Agents: Mechanisms, Evaluation, and Frontiers
S. Zhao, X. Song, T. Hu, et al. (arXiv:2603.07670, 2026)
Como o MyCockpit aplica: Aborda o Memory Paradox (acumular memória sem poda degrada a precisão do modelo). Justifica o teto rígido do MyCockpit de 8 lições e o descarte de recalls abaixo do limiar de 0.15.
AAAI 2024 · Experiential Agents
ExpeL: LLM Agents Are Experiential Learners
A. Zhao, D. Xie, Y. Zhang, M. Zhou (2024)
Como o MyCockpit aplica: Demonstra matematicamente que acumular um "pool de experiências de tentativa e erro" e destilar insights em linguagem natural supera fine-tuning tradicional para adaptação contínua.
