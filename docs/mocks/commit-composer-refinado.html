Diagnóstico Técnico do Problema Atual

  • 1. Fonte de 14px sobrescrevendo a escala: O componente primitivo components/ui/textarea.tsx possui a classe md:text-sm (14px). Como o app roda em desktop (≥ 768px), o CSS da media query prevalece sobre o text-[11px] passado pelo composer. O mesmo ocorre no Input do título.
  • 2. Expansão vertical descontrolada: A propriedade moderna field-sizing-content no textarea faz com que qualquer commit gerado com 4 ou 5 tópicos cresça indefinidamente para mais de 250px, canibalizando a visualização dos arquivos alterados.
  • 3. Anel de foco âmbar de 3px: A classe focus-visible:ring-[3px] cria uma borda espessa de atenção ao redor de todo o bloco quando em foco, causando peso visual excessivo comparado ao restante da interface.
  • 4. Monospace em bloco de texto denso: Usar font-mono em 14px num parágrafo de 5 tópicos gera uma textura pesada. O corpo deve ser em font-sans text-[11px] (ou mono compacto de 11px com entrelinha ajustada).
