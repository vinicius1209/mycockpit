# Contexto operacional do assistente, Frota

## Projeto

Frota é o produto pessoal neste diretório. O contexto técnico e as regras do
repositório estão em `../AGENTS.md`, que permanece como fonte única das
instruções de desenvolvimento.

## Como trabalhar

1. Ler `../AGENTS.md` antes de alterar código.
2. Conferir `git status` e preservar mudanças de outras frentes.
3. Consultar arquitetura, styleguide, decisões e planos relevantes.
4. Fazer mudanças pequenas, com testes ao lado do código.
5. Executar as verificações exigidas pelo projeto antes de entregar.
6. Registrar decisões estruturais em `../docs/decisions.md`, quando aplicável.
